## ◈ Projects — What I Built

> *The things I'm actually proud of.*

<br/>

### 🦾 ProstheticIQ Dashboard
```
PROBLEM  →  Prosthetic devices are tuned blindly. No analytics. No feedback loop.
SOLUTION →  Full-stack EMG analytics app that visualizes accuracy vs. comfort.
STACK    →  React · Node.js · Recharts · Docker
IMPACT   →  120 simulated sessions · 8 users · scatter plots + per-session radar charts
```

---

### 👁️ Diabetic Retinopathy Screener
```
PROBLEM  →  DR detection is expensive, slow, and requires specialist eyes.
SOLUTION →  CNN-based model classifying retinal fundus images automatically.
STACK    →  Python · TensorFlow · Keras · OpenCV
IMPACT   →  Multi-class severity detection from raw medical imaging data
```

---

### 📩 SMS Spam Detection
```
PROBLEM  →  Spam is noisy, deceptive, and context-dependent.
SOLUTION →  TF-IDF + Naïve Bayes with a full NLP preprocessing pipeline.
STACK    →  Python · Scikit-Learn · NLTK
IMPACT   →  Tokenization · stopword removal · stemming · high classification accuracy
```

---

### 🎭 Face Liveness Detection
```
PROBLEM  →  Face authentication is trivially fooled by photos.
SOLUTION →  CNN model detecting spoofed vs. genuine faces in real-time.
STACK    →  Python · OpenCV · TensorFlow
IMPACT   →  Live webcam inference · real-time anti-spoofing defense
```
